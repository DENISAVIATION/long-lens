# Long Lens

A plane-spotting quiz: one detail of a real aircraft photo, then the lens pulls back. Name the aircraft family before the zoom runs out.

Play: https://denisaviation.github.io/long-lens/

- Modes: Long Lens, Blind Stop, Tail Spotter, Sudden Death and the Daily 5
- Google sign-in, leaderboard and Spotters' Wall run on Firebase (fill in `firebase-config.js`)
